# 选择题

底层逻辑是母语直觉，总结 **易错易对** 的说法

易错如：
- 绝对化 ：**只有...才** / **只要...就**
- 因果关系 ：**之所以...是因为**
- 否定 ：**没有** / **不是**
- 拉踩 ：**A 比 B 更...**

易对如：
- 有可能 ：**有可能是因为...** (证明必然不可能很难，除非确保文中做出断言)
- 基础 ：**a,b,c 是 d 的基础** ()
- 重要 ：**a 重要** (证明不重要很难，除非文章强调不重要)
- 存在 ：**存在...的现象** (证明不存在很难，只要文中提到就很可能存在)
