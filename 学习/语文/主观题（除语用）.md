# 范式

## 答题逻辑

首先我们要通过归纳，明白答题角度是如何被想出来的，如下是主观（除部分语用）的底层逻辑：

$$
\boxed{分析题干} + \boxed{\color{yellow}{回答问题}}  \left( + \boxed{情感主旨} \right)
$$

- 分析题干： 题干有一定深层含义时，**由表入深** 地对题干 **简要概括分析**

- 回答问题： 识别 **手法题**，**作用题** 和 **原文对应题** 题型，进行作答

- 情感态度： 适当补充作者对该内容的 **情感主旨**

>  应该注意： 题干不止指的是题目的几个问句，更应该对应到原文中的具体内容

答题要具体化，每点第一句话要和原文有关，而不是上来就套模板。

聪明地，对于 **是分析还是概括** 和 **是否补充情感** 抉择不定时，在格子足够的情况下应当尽可能多写，追求内容完整性

在如上方法论的指导下，通过多刷真题和模拟题，训练 **分析题干的准确性** 和 **回答问题的规范性**，并积累答题基础知识（何手法，何作用）

同时，日常要 **训练语言组织能力** ，**丰富语言表达能力**

## 答题格式

明确答题逻辑之后，通过 **观点+举例分析** 的方式作答

## 分析题干

大白话不分析，有深层含义才分析，对题干 **简要概括分析**，即 **是什么，有什么含义（表层，深层）**

分析需要联系问题，并划分出回答问题所需要的角度

## 回答问题

对核心问题类型，大致分为

$$
\begin{cases}
\boxed{\text{手法题(how)}}
\\\boxed{\text{作用题(why)}}
\\\boxed{\text{原文对应题(what)}}
\end{cases}
$$

识别顺序：**手法题**？**作用题**？若都不是，则是**原文对应题**

对于问题的作答明细，**手法题** 和 **作用题** 都需要依附一定的基础知识，是在答题范式的地基上的建筑

### 原文对应(what)

**原文对应** 在高考中的分值比重较高，内核是 **解析**，范式是 **拆+原文对应**

即在 **分析题干** 中对题干的 **概括分析** 的基础上，对题干涉及的 **范围和角度** 进行进一步 **拆** 解，再对应着 **原文内容** 由表入深地 **解析**：
- **拆**： 向下拆解出若干个核心答题点
	- 题干涉及整文或很多段：拆成多个 **核心段**
	- 题干涉及一段：拆成多个 **核心句**
	- 涉及一句：拆成多个 **核心词**
- **原文内容**： 结合原文内容将拆得的若干答题点 **解析** 作答
#### 例子

例 1： 提问 **论证思路是什么**：
- 最快： **是什么** => **what** => **原文对应**
- 解析： **思路** 就是论点的主次和逻辑，思路不是 **手法**，且没有问 **作用效果**，我们只需解释论述顺序
- 答案（以总分顺序为例）
	- 1. 运用 总-分 的论述顺序
	- 2. 先总述 xxx
	- 3. 再从 n 个方面展开论述(1.xx 2.xx 3.xx)

### 手法题(how)

简析其 **手法**，分为 **结构和内容**，在基础知识中详叙

直接问 **用了什么手法**： 回答 **手法**

间接问 **如何取得这种效果**： 回答 **手法+语言特色（词句段）**

注意：
- 赏析本文用了那些手法 => **手法题**
- 本文使用了 xx 手法，请简要赏析 => **原文对应题**

简析其 **作用效果**，分为 **结构和内容**，在基础知识中详叙
