## 前缀和

设原始序列 $A$ 是一个 $n$ 维 `张量`，形状为 $d_{1}\times d_{2}\times\dots \times d_{n}$ ，大小为 $N=\prod\limits_{i=1}^{n} d_{i}$

定义第 $k$ 维的 `索引集合` $I_{k} = \{1,2,\dots,d_{k}\}$

> 在编程中索引集合可能是 `0-基` 的，即 $I_{k} = \{0,1,\dots,(d_{k}-1)\}$  

整个序列的 `全索引空间` 就是 `所有维度索引集合` 的 `笛卡尔积` $\mathcal{I}$ ，有：

$$
\begin{align}
\mathcal{I} &= \prod\limits_{k=1}^{n} I_{k} = I_{1}\times I_{2}\times\dots \times I_{n} \\
&= \prod\limits_{k=1}^{n} [d_{k}] = \{1,2,\dots,d_{1}\} \times \{1,2,\dots,d_{2}\} \times\dots \times \{1,2,\dots,d_{n}\} 
\end{align}
$$

那么序列 $A$ 可以严格看作是这个空间到实数域或复数域的映射 $A:\mathcal{I} \to \mathbb{R}$

对 目标位置 $\mathbf{p} = (p_{1},p_{2},\dots,p_{n})\in \mathcal{I},1\leq p_{k} \leq d_{k}$

其 `前缀子空间` $\mathcal{P}(\mathbf{p}) = \prod\limits_{k=1}^{n} [p_{k}],1\leq p_{k}\leq d_{k}$

其 `前缀和` $S(\mathbf{p}) = \sum\limits_{\mathbf{j} \in \mathcal{P}(\mathbf{p})} A(\mathbf{j})=\sum\limits_{\mathbf{j}\in \prod\limits_{k=1}^{n} \{1,\dots,p_{k}\}} A(\mathbf{j})$

## 容斥前缀和

可以采取数学容斥原理来取代多重循环来递推求 $S(\mathbf{p})$ ，其严格表达为：

$$
S(\mathbf{p}) = A(\mathbf{p}) + \sum\limits_{\text{非空集合}T \subseteq \{1,\dots,n\}} (-1)^{\lvert T\rvert + 1} \cdot S(\mathbf{p} - \mathbf{e}_{T})
$$

其中 $\mathbf{e}_{T}$ 是标准基向量之和 $\mathbf{e}_{T} = \sum\limits_{k\in T} \mathbf{e}_{k} = \sum\limits_{k\in T} \{0,\dots,0,\underbrace{1}_{\text{第 k 位}},0,\dots,0\}$

当 $n=1$ 时 $S_{i} = A_{i} + S_{i-1}$

当 $n=2$ 时 $S_{ij} = A_{i} + S_{(i-1)j} + S_{i(j-1)} - S_{(i-1)(j-1)}$

## 逐维前缀和

容斥单次递推复杂度 $O(2^{n})$ 。因此预处理复杂度为 $O(2^{n} N)$ ，维度较大时不适用，考虑优化。

我们不妨观察前缀和表达式 $S = \sum\limits_{i_{1}}\dots \sum\limits_{i_{n}}(A_{i_{1}\dots i_{n}})$

由 $n$ 重求和本身出发可以想到：每次只考虑一个维度，固定所有其他维度，然后求若干个一维前缀和，这样对所有 $k$ 个维度分别求和后，就可以得到 $k$ 维前缀和

这称为 `逐维前缀和` ，单次 $O(N)$ ，预处理只要 $O(nN)$ ，通常可以接受。

## 子集合 DP(SOS DP)

维度更大的情况，经常出现在一类叫作 `子集和` 的问题中

问题描述如下，考虑大小为 $n$ 的集合的子集上面定义的函数 $f:T \to  \mathbb{R}$ ，其中 $T \subseteq \{1,2,\dots,n\}$ ，考虑其子集和函数 $g(S) = \sum\limits_{T \subseteq S} f(T)$

这个 $T \subseteq S$ 的枚举是困难的，枚举所有子集的子集复杂度根据二项式定理有 $\sum\limits_{k=0}^{n} \dbinom{n}{k} 2^{k} = 3^{n}$

子集数本身只有 $2^{k}$ 个，我们重复处理了大量信息，考虑 DP 优化

我们用二进制考虑集合元素存在性，那么原集合的子集 $S$ 可以看作一个 $n$ 维数组，每个维度下标在 $\{0,1\}$ 中表示元素是否存在，同时可以压缩为 $n$ 位二进制数 $\texttt{s}$ 来表示。

那么问题就转化成了高维前缀和问题，考虑用逐维法分析。根据 $T \subseteq S \iff \forall i(t_{i}\leq s_{i})$ 可以推导：

对子集求和就是求这个 $n$ 为数组的前缀和，且 ${\begin{cases}s_{i}=0\implies t_{i}=0\\s_{i}=1 \implies t_{i}={0 /1}\end{cases}}$

从而得到转移 ${\begin{cases}F_{s,i} = F_{s,i-1} &\text{for } s_{i}=0 \\F_{s,i} = F_{s,i-1}+F_{[s \otimes  (1\ll i)],i-1} &\text{for } s_{i}=1\end{cases}}$

化简得 $F_{s,i} = F_{s,i-1}+s_{i}\times F_{[s \otimes  (1\ll i)],i-1}$

可以发现这类似背包问题转移，因此可以空间优化 $F_{s} += s_{i} \times F_{[s \otimes  (1\ll i)]}$



对于子集差分，与普通序列差分的处理类似，只需要把上面 `+=` 改为 `-=` 即可，本质是前缀和的逆操作
