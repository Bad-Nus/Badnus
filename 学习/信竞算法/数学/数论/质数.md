# 质数

**质数（素数）** 是 `大于 1` 且 `除了 1 和它本身外没有其他因数` 的自然数，否则为 **合数** 。

## 素数定理

**素数定理** 给出了质数 `在自然数中的密度` 和 `渐进分布` 的定量描述。

设 $\pi(x)$ 表示不超过 $x$ 的素数的个数，那么有 $\lim\limits_{ n \to \infty } \pi(n) \sim \frac{n}{\ln n}$

## 素数判断

### 暴力

根据质数定义，可以暴力判断 $2\sim (x-1)$ 是否是 $x$ 的因子。

```cpp
bool isp(int x){
	for(int i=2;i<x;++i)if(x%i==0)return 0;
	return 1;
}
```

复杂度 $O(n)$ 

### 优化

根据因数的性质 $t\mid x \iff \frac{x}{t}\mid x$ 优化，因子 $t$ 仅需从 $2$ 到 $\sqrt{x}$ 遍历。

```cpp
bool isp(int x){
	int tmp = sqrt(x);         
	for(int i=2;i<=tmp;++i)if(x%i==0)return 0;
	return 1;
}
```

复杂度 $O(\sqrt n)$

### 试除法

$6k\pm 1$ 试除法： $x\equiv b\pmod {6}\begin{cases}b=0,2,4&\implies 2\mid x \\ b=3&\implies 3\mid x \end{cases}$ 

因此用因子 $t=6k\pm{1}$ 试除。

```cpp
bool isp(int x){                    
     if(x==2||x==3)return 1;
     if(x==1||x%6!=1&&x%6!=5)return 0;//特判x<=6以及b!=1,5
     
     int tmp=sqrt(x);      
     for(int i=5;i<=tmp;i+=6)if(x%i==0||x%(i+2)==0)return 0;
     return 1;
}
```

复杂度 $O \left( \frac{\sqrt n}{3} \right)$

## 素性测试

**素性测试**（Primality test）是一类在 **不对给定数字进行素数分解**（prime factorization）的情况下，测试其是否为素数的算法。

素性测试有两种：

1. 确定性测试：绝对确定一个数是否为素数。常见示例包括 Lucas–Lehmer 测试和椭圆曲线素性证明。
2. 概率性测试：通常比确定性测试快很多，但有可能（尽管概率很小）错误地将[合数](../number-theory/basic.md#素数与合数) 识别为质数（尽管反之则不会）。因此，通过概率素性测试的数字被称为 **可能素数**，直到它们的素数可以被确定性地证明。而通过测试但实际上是合数的数字则被称为 **伪素数**。有许多特定类型的伪素数，最常见的是费马伪素数，它们是满足费马小定理的合数。概率性测试的常见示例包括 Miller–Rabin 测试。

## 线性筛质数

`判断次数足够多` 而 `质数本身较小` 时，预处理筛选出 $1\sim n$ 的所有质数，从而 $O(1)$ 地应答

### 欧拉筛

对合数 $x$ 用其质因子 $t$ 与其合数因子 $\frac{x}{t}$ 标记，再将 $x$ 作为更大合数 $x^{'}$ 的合数因子。注意这两个操作是同一的

如此只需遍历 $1 \sim n$ ，其中 $x$ 若被标记过，就将 $1\sim (x-1)$ 中质数 $t$ 从小到大取出，标记后面的 $x^{'}=xt$

为了每个合数 $x$ 只会被筛到一次，且不会多筛不属于 $1 \sim n$ 的合数，我们令 `t 是 x 的因子` 或 `x'>n` 时终止标记。

**证明第一点**：

> 在 $t$ 是 $x$ 的质因子时，对更大的 $x$ 的质因子 $p$ 满足 $px=t\left( \frac{x}{t} \times p\right)$ ，那么合数 $px$ 会被 $p$ 和 $t$ 同时筛到，因此终止标记可以保证 $px$ 只被 $p$ 所筛

因此对 $x$ 的标记是 $O(n)$ 的，同时遍历也是 $O(n)$ 的，总复杂度 $O(n)$

```cpp
bool npri[N];
vector<int>pri;
void euler(){
	rep(i,2,n){
		if(!npri[i])pri.emplace_back(i);
		for(int k:pri){
			if(i*k>n)break;
			npri[i*k]=1;
			if(i%k==0)break;
		}
	}
}
```

同时在该框架上可以顺带求出 `欧拉函数`，`莫比乌斯函数`，`最小质因子` 等积性函数

### 埃氏筛

朴素的埃氏筛用质数的一切倍数来标记合数，理论复杂度 $O(n\log\log n)$ 稍劣于欧拉筛

> 不能顺带求出积性函数

```cpp
bool npri[N];
vector<int>pri;
void euler(){
	rep(i,2,n){
		if(!npri[i]){
			pri.emplace_back(i);
			if(1LL*i*i<=n)rep(j,i,n/i)npri[j*i]=1;
		}
	}
}
```

但 bitset 优化后实际复杂度 $O\left( \frac{n\log\log n}{\omega} \right)$ ，由于 $\frac{\log\log n}{\omega}\lt 1$ 稍优于欧拉筛

```cpp
bitset<N>npri;
vector<int>pri;
void era(){
	rep(i,2,n){
		if(!npri[i]){
			pri.emplace_back(i);
			if(1LL*i*i<=n)rep(j,i,n/i)npri[j*i]=1;
		}
	}
}
```

> 代码中的 pri 仅用作收集质数，并不影响埃氏筛  

## 质因数

### 算数基本引理

设 $p$ 是素数，$p\mid a_1a_2$，那么 $p\mid a_1$ 和 $p\mid a_2$ 至少有一个成立。

算数基本引理的逆命题稍加修改可以得到素数另一种定义：

对整数 $p\ne 0,\pm 1$，若对任意满足 $p\mid a_1a_2$ 的整数 $a_1,a_2$ 均有 $p\mid a_1$ 或 $p\mid a_2$ 成立，则称 $p$ 是素数．

### 算术基本定理

任何一个大于 $1$ 的正整数 $x$ 都能位移分解成有限个质数的乘积 $x=p_{1}^{\alpha_{1}}\times p_{2}^{\alpha_{2}}\times \cdots \times p_{k}^{\alpha_{k}}$

求 $p_{i},\alpha_{i}$ 一般用试除法 `rep(i,2,sqrt(n))while(x%i==0)x/=i,++num[i]` 最后剩下的 $x$ 不一定为 $1$ ，可能是其大质因子

根据排列组合：
1. $x$ 的因数个数 $num(x) = \prod_{1}^{k}(\alpha_{i}+1)$
2. 因数之和 $sum(x)=\prod_{i=1}^{k}\left( \sum_{j=1}^{\alpha_{i}} p_{j}^{\alpha_{j}} \right) =\prod_{i=1}^{k} \left(\frac{p_{i}^{(\alpha_{i}+1)}-1}{p_{i}-1}\right)$
