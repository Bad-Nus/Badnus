# 快速幂

求 $a^{n}$ 也称二进制取幂

## 普通快速幂
求 $a^{n}$ 暴力复杂度 $O(n)$ 

考虑用倍增降低复杂度，其 $n$ 有 $\log{n} +1$ 个二进制位，那么只需用 $n$ 的二进制位 $i \in [1,\log{n}+1]$ 对应的 $a^{i}$ 幂次之积来表示 $n = \left( \sum\limits_{i=1}^{\log{n} +1} 2^{i}\right)\implies a^{n} = a^{\left( \sum\limits_{i=1}^{\log{n} +1} 2^{i}\right)} = \prod\limits_{i=1}^{\log{n} +1} a^{(2^{i})}$

时间复杂度 $O(\log{n})$

### 代码

仅表示 $t\times a^{n}$ 时可以将初始变量 $\texttt{res}$ 赋为 $t$ ，这在矩阵快速幂中具一定作用

```cpp
ll mi(ll x, ll y) {
    ll res = 1;
    while (y) {
        if (y & 1)
            res *=x;
        x *=x;
        y >>= 1;
    }
    return res;
}
```

## 带模快速幂

> 注意带模快速幂在 $\begin{cases}\pmod{1}\\ n=0\end{cases}$ 的特殊情况下要返回 $0$

```cpp
ll mi(ll x, ll y, ll mod) {
    ll res = 1;
    while (y) {
        if (y & 1)
            res = res * x % mod;
        x = x * x % mod;
        y >>= 1;
    }
    return res;
}
```
#### 简化
```cpp
ll mi(ll x,ll y,ll mod){
	ll res=1;
	for(;y;y>>=1,x=x*x%mod)if(y&1)res=res*x%mod;
	return res;
}
```

指数很大时，需要利用 `拓展欧拉定理` 降幂后处理

$$
a^b \equiv \begin{cases}
  a^{b \bmod \varphi(m)},                &\gcd(a,m) =  1,                   \\
  a^b,                                   &\gcd(a,m)\ne 1, b <   \varphi(m), \\
  a^{(b \bmod \varphi(m)) + \varphi(m)}, &\gcd(a,m)\ne 1, b \ge \varphi(m).
\end{cases} \pmod m
$$

## 高精快速幂

求 $L^{n}$ ，在普通快速幂的基础上 ，将乘法替换为高精乘即可

时间复杂度 $O(\lvert L\rvert ^{2}\log{n})$ ，其中 $\lvert L\rvert$ 表示高精度位数

```cpp
const int N = 501;
typedef vector<int> VI;
VI a(N),res(N);
int p;
VI mul (VI&a,VI&b){
	VI t(N*2);
	rep(i,0,N-1){
		rep(j,0,N-1){
			t[i+j] += a[i] * b[j];
			t[i+j+1] += t[i+j]/10;
			t[i+j] %= 10;
		}
	}
	return t;
}
VI mi(VI x,int y){
	VI res(N);
	res[0] = 1;
	while(y){
		if(y & 1)res = mul(res,a);
		a = mul(a,a);
		p >>= 1;
	}
	return res;
}
```

## 矩阵快速幂

求矩阵乘法 $A \times B^{n}$

在代码中把 $A$ 赋值给 $\texttt{res}$ ，同时将乘法改为矩阵乘法即可

> 注意不能写成 $B^{n} \times A$ ，因为矩阵乘法不符合交换律

```cpp
const int N=10,mod=1e9+7;
typedef long long ll;
struct Matrix{
    ll a[N][N];
    Matrix(){memset(a,0,sizeof(a));};
    Matrix operator*(const Matrix &b)const{
        Matrix res;
        rep(i,0,N-1)rep(k,0,N-1)if(a[i][k])rep(j,0,N-1)
            res.a[i][j]=(res.a[i][j]+a[i][k]*b.a[k][j])%mod;
        return res;
    }
};
Matrix mat_pow(Matrix x,ll y){
    Matrix res;
    rep(i,0,N-1)res.a[i][i]=1;
    while(y){
        if(y&1)res=res*x;
        x=x*x;
        y>>=1;
    }
    return res;
}
```
