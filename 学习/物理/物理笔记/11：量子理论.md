# 量子理论

## 热辐射

**本质是粒子**（光子的传递），其规律由波动性体现

表现为 **传热** 与 **发光**

## 黑体 & 黑体辐射

能完全吸收各种频段的电磁波而不发生反射，但自身会发生黑体辐射

随着温度升高，一方面各种波长的辐射强度都有所增强；另一方面，辐射强度的极大值向波长较短的方向移动

## 能量量子化

鉴于原先黑体辐射模型均在一定情境下脱离现实（紫外灾难），普朗克提出了能量量子化：

1. 微观粒子的能量是不连续的，而是分立的
2. 每份最小能量为 $\varepsilon = h \nu$ 

这份最小能量单位就是光子的雏形，启迪了爱因斯坦对光电效应的解释，标志着量子论的诞生。

## 光电效应

用光照射金属，电子吸收能量后从表面逃逸

在实验中得到四个核心规律：

1. 存在截止频率 $\nu_{c}$ ：对每种金属，当入射光频率低于某个极限 $\nu_{c}$ ，无论光强多大，都打不出电子
2. 最大初动能只取决于 $\nu$ ： $E_{k\text{ max}}$ 随 $\nu$ 线性增长，与光强无关。
3. 瞬时性：只要频率超过介质频率，电子几乎瞬间溢出，毫无时间延迟
4. 饱和光电流与光强成正比：电压足够大时，所有溢出电子都到达阳极，此时光电流大小与入射光强成正比，证明光强决定电子数

这些实验规律中，存在许多违背经典波动理论的实验现象，对此爱因斯坦基于普朗克的能量量子化，提出了光子假说：

1. 光子的能量也是不连续的，分立的
2. 一束光就是一束以光速运动的光子流
3. 每个的能量与频率成正比 $\varepsilon = h \nu$

根据爱因斯坦的光子假说，有 $h\nu = W_{0} + E_{k\text{ max}}$ ，其中：

1. $W_{0}$ 为逸出功：电子逃出金属表面所需的最小能量，只与金属材料有关
2. $E_{k \text{ max}}$ 为最大初动能：溢出之后的理论最大动能

这样很好地解释了波动理论无法解释地诸多现象，即光电效应的本质是粒子撞击而非波的能量积累

以此，我们可以进一步导出光电效应中，光电管不同电压下的光电流的规律，即 $I-U$ 曲线：

1. 最大动能与反向电压恰好抵消时，有 $eU_{c} = E_{k\text{ max}} = h\nu -W_{0} \implies U_{c} = \frac{h\nu}{e} - \frac{w_{0}}{e}$
2. 饱和光电流电压足够大时，所有光电子都到阳极，电流不再增大，其大小与入射光强成正比

## 康普顿效应

通过研究 **石墨对 X 射线的散射的实验** ，发现了存在能量相对减少，波长相对增长的光线

其实质是： **散射的光子撞击电子动量减小**，故而频率减小，波长增大

意义：

1. 证明爱因斯坦光子说的正确性（光子）
2. 揭示了光不仅有动能，还有动量
3. 证实了在微观粒子的单个碰撞事件中，动能与动量守恒定律依旧成立

## 德布罗意物质波

在普朗克和爱因斯坦的启发下，**德布罗意** 类比地设想实物粒子都具有波粒二象性

- 基于爱因斯坦质能方程 $E=mc^{2}$ 和普朗克关系式 $E=h\nu$ ，与 $\begin{cases}p=mc\\ \lambda = \frac{c}{\nu} =cT\end{cases}$ 联立，得 $\begin{cases} m= \frac{h\nu}{c^{2}} = \frac{h}{\lambda c}\\ p = \frac{h\nu}{c} = \frac{h}{\lambda} \end{cases}$ 

其中 $\lambda , \nu ,T$ 体现波动性，而 $m,c,p,E$ 体现粒子性

最终 $p = \frac{h}{\lambda}$ 被称为德布罗意波长公式

综上有 $\boxed{p = \dfrac{h}{\lambda} = \dfrac{h\nu}{c} = \dfrac{E}{c}}$
