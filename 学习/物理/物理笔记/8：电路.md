# 电路

高中范围内，主要探讨“理想”电路（除高频交流），即接受 **集总假设** ：

>  电路中的电场和磁场能量被认为完全集中在电阻，电容，电感等原件内部，链接导线这只是理想导体，既不耗能也不储能，没有电磁辐射。

这个假设成立的条件是：

>  电路的物理尺寸远小于信号的波长 $d\ll \frac{d}{10}$

当不满足时，导线上的分布电感和电容效应就不能忽略，例如 $3\text{GHz}$ 的高频交流电路中信号波长为 $10\text{cm}$ ，这时几厘米长的导线都要当作传输线来处理。

在集总假设下，电学的基本定律可直接使用，用以分析 **直流稳态电路** 和 **简单交流电路**

## 电流微观表达式

- 导线单位体积自由电荷数 $n$ ，则电流 $I = \dfrac{q}{t} = \dfrac{Ne}{t} = \dfrac{nVe}{t} = \dfrac{neSL}{t} = neSv$

## 闭合电路欧姆定律

- 部分电路欧姆定律 $I=\dfrac{U}{R}$ 使用与任意一段纯电阻电路

- 闭合电路欧姆定律 $I = \dfrac{E}{R+r} ,U_{路} = E-Ir$

- 电阻定律 $R=\rho \frac{l}{S}$

- 焦耳定律与功率 $Q=I^{2}Rt,P = UI$

## 等效简化

-  串并联简化： 通过串联分压，并联分流，直接求等效电阻

- 等电势节点法： 将电路中电势相同的点标出，并重建电路图

## 功率分析

- 对整个路段功率 $P_{路} = IU_{路} = I^{2}R = \dfrac{E^{2}R}{(R+r)^{2}} = \dfrac{E^{2}R}{(R-r)^{2}+4Rr} = \dfrac{E^{2}}{\frac{(R-r)^{2}}{R} +4r}\le \dfrac{E^{2}}{4r}$
- 对路段部分可变电阻，把除可变电阻 $R_x$ 以外的部分等效为新电源 $(E^{'},r^{'})$ 则 $P_{x}=\dfrac{(E^{'})^{2}}{4r'}$
- 其效率 $\eta = \dfrac{U_{路}}{E} = \dfrac{R}{R+r} = \dfrac{R^{'}}{R^{'}+r^{'}}$
