# 运动学

讨论物体 $a,v,x$ 本质是牛二： $\vec{F} = m\vec{a}$

表现为：

$$
\begin{cases}
\vec{a}=\dfrac{d\vec{v}}{dt}=\dfrac{d^{2}\vec{x}}{dt^{2}}\\
\vec{v}(t) = \vec{v}_{0} + \int_{0}^{t} \vec{a}(\tau)d\tau\\
\vec{x}(t) = \vec{x}_{0} + \int_{0}^{t} \vec{v}(\tau)d\tau
\end{cases}
$$

在匀变速直线运动中，有 $\begin{cases}\vec{v}(t) = \vec{v_{0}} + \vec{a} t\\ \vec{x}(t) = \vec{x_{0}} + \vec{v_{0}} t + \dfrac{1}{2}\vec{a}t^{2}\end{cases}$

## 匀速运动基本公式

记忆：54321

### 五个基本公式

1. 少 $v_{0}$ 的公式： $x = v_{t} t - \frac{1}{2} a t^2$

2. 少 $v_{t}$ 的公式： $x = v_{0} t + \frac{1}{2} a t^2$

3. 少 $a$ 的公式： $x = \left( \frac{v_{0} + v_{t}}{2} \right) t$

4. 少 $t$ 的公式： $2ax = v_{t}^2 - v_{0}^2$

5. 少 $x$ 的公式： $v_{t} = v_{0} + at$

### 四个比例式

1. 等时总位移比：$1^2 : 2^2 : 3^2 : 4^2 : \cdots : \boxed{n^2}$

2. 等时第位移比：$1 : 3 : 5 : 7 : \cdots : \boxed{2n-1}$

3. 等位总时间比：$1 : \sqrt{2} : \sqrt{3} : \sqrt{4} : \cdots : \boxed{\sqrt{n}}$

4. 等位第时间比：$1 : \sqrt{2} - 1 : \sqrt{3} - \sqrt{2} : \sqrt{4} - \sqrt{3} : \cdots : \boxed{\sqrt{n}-\sqrt{n-1}}$

### 三个速度

1. 平均速度：$\bar{v} = \frac{x}{t}$

2. 中间时刻速度：$v_{\frac{t}{2}} = \frac{v_{0} + v_{t}}{2}$

3. 中间位移速度：$v_{\frac{x}{2}} = \sqrt{\frac{v_{0}^2 + v_{t}^2}{2}} \gt v_{\frac{t}{2}}$

### 两段运动

- 0-v-0 模型 $\frac{a_{1}}{a_{2}} = \frac{t_{2}}{t_{1}} = \frac{x_{2}}{x_{1}}$

### 一个打点计时器

由匀加速基本位移公式 $x_{i} = \left[ v_{0} + (i-1)a T\right]\cdot T + \frac{1}{2} a T^2$ 可以得到：

- 位移差公式 $x_{m} - x_{n} = (m-n) a T^2$

### 打点计时器

设纸带有 $N+1$ 个测量点 $( X_{1} \sim X_{N+1} )$ ，打点周期为 $T$ ，测量点 $X_{i+1}$ 到 $X_{i}$ 的距离为 $x_{i} =X_{i+1}-X_{i}$ ，求物体的 **平均加速度** $\bar {a}$

令 $k = \lceil \frac{N}{2}\rceil , p = N\%2$ ，则：

- 位移差公式 $x_{m} - x_{n} = (m-n)a T^2$ 

- 整理得 $a_{j} = \left( \frac{ x_{j+k}-x_{j} }{kT^2} \right)$

- 得到逐差法 $\bar {a} = \frac{1}{k-p} \sum\limits_{j=1}^{k-p}a_{j}=  \frac{1}{(k-p)} \sum\limits_{j=1}^{k-p}\frac{(x_{j+k}-x_{j})}{kT^{2}}$

## 渡河问题

题面：河宽 $d$ ，两岸平行，已知水速 $\vec{v_{s}}$ 和船速 $\vec{v_{c}}$ ，求渡河时间 $t$

以水流方向 $\vec{v_{s}}=v_{s}\hat{i}$ 为 $x$ 轴正向，垂直河岸向为 $y$ 轴正向。设船速大小 $v_{c}$ 且船头与河岸的夹角 ${\theta} = \langle\vec{v_{c}},x^{-}\rangle$ 

一般地，有 $v_{x} = v_{s} - v_{c}\cos{\theta},v_{y}=v_{c}\sin{\theta},t = \frac{d}{v_{y}}$

### 最快渡河

- $v_{y}$ 取最大，即 $\theta = \frac{\pi}{2}$ ，此时 $\begin{cases}t = \frac{d}{v_{c}}\\ x = v_{s}t = \frac{v_{s}}{v_{c}}d\\ s=\sqrt{x^2 + d^2} = \sqrt{\left(\frac{v_{s}}{v_{c}}d\right)^{2} + d^{2}} = d \sqrt{1 + \left(\frac{v_{s}}{v_{c}}\right)^{2}} \end{cases}$

### 最短渡河

1. $v_{c} \gt v_{s}$ 时，可以垂直过河，令 $v_{x} = 0$ 得 $\begin{cases}\cos{\theta}=\frac{v_{s}}{v_{c}} \\ t_{1} = \frac{d}{v_{y}} = \frac{d}{v_{c}\sin{\theta}}\end{cases}$
2. $v_{c}\le v_{s}$ 时，不可垂直过河，最短位移时 $\vec{v}\perp v_{c}$ 有 $\begin{cases}\cos{\theta} = \frac{v_{c}}{v_{s}} = \frac{d}{s_{min}}  \\ t_{2} = \frac{d}{v_{y}} = \frac{d}{v_{c} \sin{\theta}} \end{cases}$

- 化简得 $\begin{cases}t_{1} = \frac{d}{\sqrt{v_{c}^{2} - v_{s}^{2}}} \\t_{2} = \left(\frac{v_{s}}{v_{c}\sqrt{v_{s}^{2} - v_{c}^{2} }}\right)d \end{cases}$

## 抛体运动

即匀变速运动，加速度为常矢量，常考正交分解 $\vec{a},\vec{v}$ 求 $x,y,t$

### 自由落体

- 取 $\vec{a} = \vec{g}$ 方向为 $y$ 轴正向， $\vec{v_{0}}=0$ ，有： $\begin{cases}h = \frac{1}{2} g t^{2}\\ t= \sqrt{\frac{2h}{g}}\\ v_{y} = \sqrt{2hg}\end{cases}$

### 竖直上抛

- 取 $\vec{a}= \vec{g}$ 方向为 $y$ 轴正向， $\vec{v_{0}}\lt 0$ ，有： $\begin{cases}t_{1}=\frac{v_0}{g},v_{1}=0\\h_{min} = H = \frac{1}{2}gt_{1}^{2} = \frac{v_{0}^2}{2g}\\t_{2}=\frac{2v_{0}}{g},v_{2} = -v_{0}\\y = - v_{0} t + \frac{1}{2}gt^{2}\end{cases}$

其中 $t_{1}$ 时上抛至最高， $t_{2}$ 时回到原点，其后继续下落

### 平抛运动

- 以抛出点 $O$ 为原点，初速度 $\vec{v_{0}}$ 方向为 $x$ 轴正向，加速度 $\vec{a} = \vec{g}$ 方向为 $y$ 轴正向，则有： $\begin{cases}v_{x} = v_{0} &,v_{y} = gt\\x = v_{0} t &, y=\frac{1}{2}gt^{2}\end{cases}\implies h = y = \frac{g}{2 v_{0}^{2}} x^{2}$

重要结论：
1. 时间： $t = \sqrt{\frac{2h}{g}}$ 
2. 射程： $X = v_{0} t = v_{0}\sqrt{\frac{2h}{g}}$ 
3. 落地速度： $v_{t} = \sqrt{v_{0}^2 + v_{y}^2} = \sqrt{v_{0}^2 + (gt)^2} = \sqrt{v_{0}^2 + 2gh}$ 
4. 位移： $s = \sqrt{x^2 + y^2} = \sqrt{(v_0 t)^2 + \left( \frac{1}{2}gt^2 \right)^2}$ 
5. 位移角： $\tan\theta = \frac{y}{x} = \frac{g}{2v_0}t$ 
6. 速度角： $\tan\alpha = \frac{v_y}{v_x} = 2\frac{y}{x}$
7. 推论：速度反向延长线过水平位移中点 $\tan\alpha = 2\tan\theta$ 

### 平抛临界问题 （网球问题）

- 击球高度 $H$ ，网高 $h_{0}$ ，网距 $L_{1}$ ，底线距 $L_{1} + L_{2}$

则有：

1. 擦网最小速： $\begin{cases}L_{1} = v_{min} t_{1}\\ H-h_{0} = \frac{1}{2}gt_{1}^{2} \end{cases}\implies v_{min} = L_{1}\sqrt{\frac{g}{2(H-h_{0})}}$
2. 压线最大速： $\begin{cases}L_{1}+L_{2} = v_{max} t_{2}\\ H = \frac{1}{2}gt_{2}^{2} \end{cases}\implies v_{max} = (L_{1}+L_{2})\sqrt{\frac{g}{2H}}$
3. 既擦网又压线临界高度： $\begin{cases}\frac{t_{1}}{t_{2}} = \frac{L_{1}}{L_{1} + L_{2}}\\ \frac{H-h_{0}}{H} = \left(\frac{t_{1}}{t_{2}}\right)^{2} \end{cases}\implies H = \frac{H-h_{0}}{\left(\frac{L_{1}}{L_{1} + L_{2}}\right)^{2}} = \left(H-h_{0}\right)\left( \frac{L_{1} + L_{2}}{L_{1}}\right)^{2}$

### 斜抛运动

- 以抛出点 $O$ 为原点，水平 $x$ 轴沿初速 $\vec{v_{0}}$ 水平分方向，数值向下为 $y$ 轴正向，设 $\alpha = \langle \vec{v_{0}},{x}^{+}\rangle$ 
- 则有： $\begin{cases}v_{x} &= v_{0}\cos{\alpha}  \\  v_{y} &= -v_{0}\sin{\alpha} + gt\\x &= (v_{0}\cos{\alpha}) t  \\   y &= - (v_{0}\sin{\alpha}) t + \frac{1}{2} g t^{2}\end{cases}$
- 整理得 $y = - (\tan{\alpha})x + \frac{g}{2 v_{0}^{2}\cos{\alpha}^{2}} x^{2}$

重要结论：
1. 上升时间： $v_{y} = 0 \implies t_{1} = \boxed{\frac{v_{0}\sin{\alpha}}{g}}$
2. 射高： $H = (v_{0}\sin{\alpha}) t_{1} - \dfrac{1}{2} g t_{1}^{2} = \dfrac{1}{2} g t_{1}^{2} = \boxed{\dfrac{v_{0}^{2}\sin^{2}{\alpha}}{2 g}}$
3. 飞行时间： $y = 0\implies t_{2} = \boxed{\frac{2 v_{0}\sin{\alpha}}{g}}$
4. 射程（同高度）： $X = (v_{0}\cos{\alpha}) t_{2} = \boxed{\frac{v_{0}^{2}\sin{2 \alpha}}{g}} \le \boxed{\frac{v_{0}^{2}}{g}}$ 当仅 $\alpha = \frac{\pi}{4}$ 时取等
5. 抛射角 $\alpha$ 与 $\frac{\pi}{2} - \alpha$ 的射程 $X$ 相等

## 圆周运动

$F_{n} = m a_{n} = m \dfrac{v^{2}}{r} = mr{\omega}^{2}$ 匀速圆周运动

### 匀速圆周运动

物理量关系：
1. 线速度： $v = \dfrac{\Delta s}{\Delta t} = \omega r= \dfrac{\Delta \theta}{\Delta t} r = \left( \dfrac{2\pi}{T} \right) r = 2\pi n r$ 
2. 角速度： $\omega = \frac{\Delta \theta}{\Delta t} = \frac{2\pi}{T} = 2\pi n = \frac{v}{r}$ 
3. 向心力： $F_{\text{向}} = ma = m\frac{v^{2}}{r} = m{\omega}^{2} r = m\left(\frac{2\pi}{T} \right)^{2} r = 4m\pi^{2} n^{2} r = m{\omega} v$ 
4. 向心加速度： $a = \frac{F_{\text{向}}}{m} = \dots = \omega v$ 

### 传动装置

1. 共轴转动： $\omega_{A} = \omega_{B}$ ， $T_{A} = T_{B}$ ， $\dfrac{v_{A}}{v_{B}} = \dfrac{r_{A}}{r_{B}}$ 
2. 齿轮（异轴）传动： $v_A = v_B$ ， $\frac{{\omega}_{A}}{{\omega}_{B}} = \frac{r_{B}}{r_{A}} = \frac{n_{B}}{n_{A}}$ ， $\frac{T_{A}}{T_{B}} = \frac{r_{A}}{r_{B}} = \frac{n_{A}}{n_{B}}$ 

### 变速圆周运动

#### 火车转弯

轨道倾角 $\alpha$ ，轨距 $L$ ，高度差 $h$ ，故有：

$$F_{\text{合}} = mg\tan\alpha \approx mg\sin\alpha = mg \cdot \frac{h}{L} = F_{\text{向}} = m\frac{v_{0}^{2}}{R} \implies v_{0} = \sqrt{\frac{Rgh}{L}}$$

结论：
1. $v > v_{0}$ 时，超速，挤压外轨
2. $v < v_{0}$ 时，低速，挤压内轨

#### 拱桥

1. 对最高点甲处： $F_{\text{向}} = mg - F_{N} = m\frac{v^{2}}{r} \implies F_{N} = mg - m\frac{v^{2}}{r}$ 
2. 对最低点乙处： $F_{\text{向}} = F_{N} - mg = m\frac{v^{2}}{r} \implies F_{N} = mg + m\frac{v^{2}}{r}$
- 在最高点处临界 $F_{N} =0$ 时飞离

#### 绳轨约束

即最高点无支撑
1. 最高点有： $F_{\text{弹}} + mg = m\frac{v^2}{R}$ 
2. 最高点临界： $F_{\text{弹}} = 0$ 时 $v_{\text{高}} = \sqrt{Rg}$ 
3. 最低点临界：由动能定理 $\frac{1}{2}mv_{\text{低}}^{2} = \frac{1}{2} m v_{\text{高}}^{2} + 2mgR \implies v_{\text{低}} = \sqrt{ 5gR }$

#### 杆、双轨约束

即最高点有支撑
1. 最高点有： $mg \pm F_{\text{弹}} = m\frac{v^2}{R}$ 
2. 临界： $F_{\text{弹}} = 0$ 时 $v_{\text{min}} = 0$ 

## 天体运动

### 基本公式

记中心天体质量 $M$ ，半径 $R$ 。环绕天体质量 $m$ ，其中心距中心天体表面高度为 $h$

理想状态下，物体受万有引力做匀速圆周，其半径 $r = R + h$

则有： $G\frac{Mm}{r^{2}} = \begin{cases} m\frac{v^{2}}{r} &\implies \boxed{v} = \sqrt{\frac{GM}{r}} = \sqrt{\frac{gR^2}{r}} \\ m{\omega}^{2} r &\implies \boxed{\omega} = \sqrt{\frac{GM}{r^{3}}} = \sqrt{\frac{gR^{2}}{r^{3}}} \\ m\left(\frac{2\pi}{T}\right)^{2} r &\implies \boxed{T} = \sqrt{\frac{4\pi^{2} r^{3}}{GM}} = \sqrt{\frac{4\pi^{2} r^{3}}{gR^{2}}} \\ m a_{n} &\implies \boxed{a_{n}} = \frac{GM}{r^{2}} = \frac{gR^{2}}{r^{2}} \end{cases}$
### 开普勒三定律

1. **轨道定律**：所有行星绕太阳的轨道都是椭圆，太阳在椭圆焦点
2. **面积定律**：对任意行星，它与太阳连线在相等时间内扫过的面积相等（ $vr\sin{\theta} = k$ ）
3. **周期定律**：所有行星半长轴三次方跟它周期的二次方的比值相等，即 $\frac{a^{3}}{T^{2}}  = \frac{GM}{4{\pi}^{2}}\implies T^{2}MG = 4{\pi}^{2}a^{3}$
### 地球重力加速度

在地表，由于物体随地球自转，万有引力提供重力和向心力。同时不同维度和海拔

对 `忽略自转影响的 “地表” ` 或 `不随地自转的 “地面附近” `，不考虑自转产生的向心力，可以导出黄金代换式[^1]

- 黄金代换 $G\frac{Mm}{R^{2}} = mg \implies GM = gR^{2}$

考虑向心力时，需考虑维度和海拔

   - 纬度越高，$g$ 越大
   - 海拔升高，$g$ 减小，近似关系为 $g_h \approx g_0 \left(1 - \dfrac{2h}{R}\right)$
   - 在地球内部 $g(r) = \dfrac{GM(r)}{r^2} = \dfrac{GMmr}{R^{3}}=\dfrac{4\pi}{3} G\rho r \boxed{\propto r}$


### 宇宙速度

1. **第一宇宙速度**：天体环绕地球所需速度（最小发射，最大环绕速度） $G\dfrac{Mm}{R^{2}} = m\dfrac{v^{2}}{R} \implies v_{1} = \sqrt{\dfrac{GM}{R}} \approx 7.9\ \text{km/s}$ 
2. **第二宇宙速度**：天体挣脱 **地球引力** 束缚的最小发射速度 ${\int} \left( \dfrac{GMm}{r^{2}} \right) = \dfrac{1}{2} m v^{2} \implies v_{2} =\sqrt{\dfrac{2GM_{0}}{R}} = \sqrt{2}\cdot v_{1}= 11.2\ \text{km/s}$ 
3. **第三宇宙速度**：天体挣脱 **太阳引力** 束缚的最小发射速度 $v_{3} = 16.7\ \text{km/s}$ 

对第三宇宙速度的简单推导：

在 **不加考虑相对速度和参考系的变化的前提** 下，排除任何地球影响，挣脱太阳引力的最小发射速度 $v_{4} = 12.4 \text{ km/s}$

那么考虑地球影响，第三宇宙速度为 $V = \sqrt{v_{2}^{2} + v_{4}^{2}} =\sqrt{(11.2)^{2} + (12.4)^{2}} = 16.7 \text{ km/s}$

### 天体能量

- 对天体动能与势能，有： $\begin{cases}E_{k} = \frac{1}{2} mv^{2} = \frac{1}{2} m \frac{GM}{r}\\E_{p} = - \int_{r}^{\infty} \frac{GMm} {{\tau}^{2}} d{\tau}= \frac{-GMm}{r}\\E = E_{k} + E_{p} = - \frac{1}{2} \frac{GMm}{r}\\ \end{cases}$
	- 故轨道半径 $r$ 越大时，动能越小，势能越大，总能量越大。同时由开普勒第三定律，周期 $T^{2} \propto r^{3}$ 越大。

### 变轨

根本原因： 由天体能量公式， $v \downarrow$ 近心， $v \uparrow$ 离心。

基本模型（两次加速模型）：

$$\boxed{\text{近地轨道 }v_{1}} \stackrel{\text{加速}}{\implies} \boxed{\text{椭圆轨道近地点 }v_{2}} \implies \boxed{\text{椭圆轨道远地点 }v_{3}} \stackrel{\text{加速}}{\implies} \boxed{\text{同步轨道 } v_{4}}$$

则得 $v_{2} > v_{1}$ ， $v_{4} > v_{3}$ ， $v_{1} > v_{4} \implies v_{2} > v_{1} > v_{4} > v_{3}$ 

- 即 $\boxed{\text{椭圆轨道近地点 }v_{2}} \gt \boxed{\text{近地轨道 }v_{1}} \gt \boxed{\text{同步轨道 } v_{4}} \gt \boxed{\text{椭圆轨道远地点 }v_{3}}$

### 二级结论

#### 求中心天体质量 $M$ 和密度 

- 由 $M=\rho V=\rho \cdot \frac{4}{3} {\pi} R^{3}$ 得 $\begin{cases}mg = G\frac{Mm}{R^{2}} & \boxed{\text{g,R 法}}\\G\frac{Mm}{r^{2}} = m\left( \frac{2\pi}{T} \right)^{2} r & \boxed{\text{T,r 法}} \end{cases}\implies \begin{cases}M = \frac{4\pi^{2} r^{3}}{GT^{2}} = \frac{gR^{2}}{G} \\\rho = \frac{3\pi r^{3}}{GT^{2} R^{3}}  = \frac{3g}{4\pi R G} \end{cases}$

#### 双星模型

- 由 $\begin{cases} G\frac{m_{1} m_{2}}{L^{2}} = m_{1} {\omega}^{2} r_{1} \\ G\frac{m_{1} m_{2}}{L^{2}} = m_{2} {\omega}^{2} r_{2} \end{cases}$ 得 $\frac{m_{2}}{m_{1}} = \frac{r_{1}}{r_{2}} \implies m_{1} r_{1} = m_{2} r_{2}$

- 两式相加，结合 $M = m_{1} + m_{2} ,L = r_{1} + r_{2}$ ，使该式与开普勒第三定律公式同构： $\frac{GM}{L^2} = \frac{4\pi^{2}L}{T^2} \implies T^{2}MG = 4{\pi}^{2}L^{3}$
