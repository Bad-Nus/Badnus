# 听力

赋分，不必细究

# 选择题

**先看题干**，再 **对应文章看**，最后 **看选项**：防止从选项带上错误主观色彩

**包含主旨大意的优先选**，除非出现明显逻辑谬误，否则不必辩理

# 语法填空

做题不能大意，时刻 **结合全文** 做单词变形

# 作文

本质是一个 **中文写作+英文翻译**

应用文不跑题，列提纲

大作文积累表达，保证翻译通顺，多用好句
